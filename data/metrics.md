# 零售销售数据指标口径（sales 表）

## 表结构

sales 表字段：

| 字段 | 含义 |
|------|------|
| order_id | 订单号（整数，唯一） |
| order_date | 下单日期（DATE，格式 YYYY-MM-DD） |
| region | 地区（华东 / 华北 / 华南 / 西南 / 西北） |
| category | 品类（3C数码 / 家用电器 / 服装鞋包 / 食品饮料 / 美妆个护） |
| product | 商品名 |
| quantity | 数量（件） |
| unit_price | 单价（元） |
| amount | 订单金额（元）= quantity × unit_price |

## 指标定义

- **销售额（revenue）**：一段时间内所有订单 `amount` 求和。
- **销量**：`quantity` 求和。
- **订单数**：`order_id` 去重计数。
- **客单价**：销售额 ÷ 订单数。
- **同比**：本期 ÷ 去年同期 − 1；去年无数据时如实说明无法计算。
- **环比**：本期 ÷ 上一周期 − 1。
- **占比**：某地区 / 品类销售额 ÷ 总销售额。
- **TOP 排名**：按销售额降序取前 N 的地区或品类。

## 注意事项

- 「销售额」默认指 `amount` 求和，**不含税**（本数据无税额字段）。
- 「季度」按自然季度：Q1 = 1–3 月，Q2 = 4–6 月，Q3 = 7–9 月，Q4 = 10–12 月。
- `order_date` 是 DATE 类型，可用 `year()` / `month()` / `quarter` 等函数，无需手动截字符串。
